# مركز الصديق — تطبيق iPhone

نسخة iOS (SwiftUI، iOS 15 فأحدث) من تطبيق مركز الصديق لتعليم القرآن الكريم، بنفس تصميم ومزايا نسخة Android
([55dmom/alsiddiq-app](https://github.com/55dmom/alsiddiq-app)): أربعة أنواع حسابات (الإدارة، المعلم، الطالب، ولي الأمر)،
الحلقات، الطلاب، الحفظ والتسميع والمراجعة، الحضور، التقارير، المكافآت، الإعلانات والإشعارات. عربي بالكامل RTL.

- البنية: `AlSiddiq/Sources` — النماذج والصلاحيات والإحصائيات، واجهة المستودع `AppRepository` وتطبيقاتها، والواجهات.
- لا توجد أي مفاتيح سرية في الكود. عنوان الخادم والمفتاح العام (anon) يُمرَّران وقت البناء من متغيرات GitHub Actions
  `SUPABASE_URL` و `SUPABASE_ANON_KEY`. بدونها يعمل التطبيق في الوضع التجريبي (يظهر شريط «وضع تجريبي»).

## البناء
كل دفع إلى `main` يبني ملف `.ipa` غير موقّع على GitHub Actions (XcodeGen + Xcode)، ويلتقط صور الشاشات على محاكي iPhone،
وينشرها في Releases. وقّع الملف بنفسك قبل التثبيت.
